# Weather

A simple glassmorphic weather app powered by the free [Open-Meteo API](https://open-meteo.com/) (no API key needed). Defaults to Boca Raton, FL, with city search.

## Files
- `index.html` – page layout
- `style.css` – glassmorphic styling
- `app.js` – fetches and renders weather data

## Run locally
Open `index.html` in a browser.

## Deploy to Netlify
Drag the project folder into Netlify, or connect this repo with no build command and publish directory `/`.
